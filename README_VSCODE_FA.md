# اجرای خشت در VS Code (نسخهٔ اصلاح‌شده)

این بسته برای اجرای محلی با Node.js است. نیازی به حساب Cloudflare، ورود ChatGPT، کلید سرویس یا انتشار سایت برای استفادهٔ محلی نیست. موتور Cloudflare به‌صورت محلی روی رایانه شبیه‌سازی می‌شود و پایگاه داده و فایل‌ها در همان رایانه می‌مانند.

## شروع سریع

۱. Node.js (نسخهٔ ۲۰٫۱۹ یا ۲۲ به بالا) را نصب کنید و با `node -v` نسخه را بررسی کنید.

۲. فایل ZIP را از حالت فشرده خارج کنید و پوشهٔ استخراج‌شده را مستقیماً در VS Code با **File → Open Folder** باز کنید (یا فایل `Khesht.code-workspace` را باز کنید).

۳. در **Terminal → New Terminal** فقط یکی از دستورهای زیر را اجرا کنید (یا کلید **F5** را در VS Code بزنید):

```bash
npm run local
```

*(اگر وابستگی‌های `node_modules` هنوز نصب نشده باشند، اسکریپت به‌طور خودکار `npm ci` را اجرا می‌کند. همچنین می‌توانید در ویندوز روی `run-local.bat` دوبار کلیک کنید یا در مک/لینوکس `./run-local.sh` را اجرا کنید.)*

۴. پس از ساخت و اعمال خودکار مهاجرت‌های پایگاه داده، **نشانی ورود، ایمیل (`owner@khesht.test`) و گذرواژهٔ مدیر محلی در انتهای ترمینال نمایش داده می‌شوند** (و یک نسخه از آن در `.wrangler/local-credentials.txt` نیز ذخیره می‌شود تا در اجراهای بعدی گم نشود):

http://127.0.0.1:5173/auth
(یا http://localhost:5173/auth)

## دستورهای کاربردی

- `npm run local`: نصب خودکار (در صورت نیاز)، ساخت، مهاجرت پایگاه و اجرای سرور محلی روی درگاه `5173`.
- `npm run dev`: سرور توسعه با بازخوانی زنده (Live Reload) روی درگاه `5173`.
- `npm start`: اجرای مستقیم سرور محلی (در صورت نبود ساخت یا پایگاه، ابتدا راه‌اندازی اولیه را خودکار انجام می‌دهد).
- `npm run auth:reset`: ساخت گذرواژهٔ جدید برای حساب مدیر محلی (`owner@khesht.test`) و نمایش آن در ترمینال.
- `npm run typecheck`: بررسی خطاهای TypeScript.
- برای توقف سرور `Ctrl+C` بزنید.
